Library Management System

Build a CLI-based Library Management System.

The application manages books, members, borrowing, returning, searching, and reports.

Create:

│
├── main.py

├── models/

What the application should do

The library should allow you to:

Books
Add a book
Remove a book
Update book information
Search books
View all books
Find available books
Find borrowed books
Sort books

A book should have information such as:

Book ID
Title
Author
Category
ISBN
Publication year
Availability
Members

Allow the library to:

Register member
Remove member
Search member
View members
View member's borrowed books

A member could contain:

Member ID
Name
Email
Phone
Membership date
Borrowed books
Borrowing

A member should be able to borrow a book.

The system should check:

Does the book exist?
        ↓
Is the member registered?
        ↓
Is the book available?
        ↓
Has the member reached borrowing limit?
        ↓
Create loan
Returning

A member should be able to return a book.

The system should determine:

Was the book actually borrowed?
        ↓
When was it borrowed?
        ↓
When was it returned?
        ↓
Was it returned late?
        ↓
Calculate fine

Important OOP challenge

Use inheritance.

Create:

                 Book
                  |
          ┌───────┴────────┐
          ↓                ↓
     PhysicalBook       EBook

Both are books, but they can behave differently.

For example:

Physical book

Can be borrowed
Has shelf location

EBook

Can be downloaded
Has file size
May not have a physical shelf

Use this to practice:

inheritance
super()
method overriding
polymorphism
